## Use the materials

Try each task before opening the answer or example. Keep your working, compare the reasoning and retry a question you missed. Teachers can print attributed copies for study and classroom practice. See [copying permission](COPYING.md).

The IELTS model is illustrative and unscored. The Computer Science worksheet covers part of Cambridge 9618 information representation. These are original FocusED practice materials, not official examination papers, examiner marks or publisher endorsements. Official format/syllabus references are linked in each resource.

## Check the binary calculations

With Node.js 20 or newer, no package installation is needed:

    node --test worksheets/binary-worksheet.test.mjs

The checks validate the authored conversions, signed arithmetic, overflow, sign extension and edge case. They do not predict an examination result.
